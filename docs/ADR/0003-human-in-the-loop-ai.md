# ADR 0003: Every AI decision is approved by a human

- Status: accepted (2026-10-14)
- Context: scope v0.3, section 13 (decision 11).

## Decision

AI output is always stored as a **suggestion** with its model, input reference and timestamp. Nothing
generated by a model is published, rejected, ranked or sent to another user until a person accepts it:

- listing attributes and texts: the landlord confirms each suggestion,
- new filter-schema values: backoffice approves,
- moderation verdicts (listings, messages): a moderator decides,
- applicant summaries and scores: shown to the landlord as clearly labelled assistance, never auto-reject,
- photo tags and privacy flags: the landlord or a moderator confirms.

## Consequences

- Data model: suggestion tables (`*_suggestions`) with `status = pending|accepted|rejected`, `decided_by`, `decided_at`.
- UI always shows what the AI proposed and lets the user edit before accepting.
- AI features sit behind feature flags; mock implementations exist so the product works with AI turned off.
